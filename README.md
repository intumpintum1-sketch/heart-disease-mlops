# heart-disease-mlops
MLOPS Project 
Heart Disease MLOps Project
============================

MLOps Experimental Learning Assignment 01

Objective
---------
Build an end-to-end machine learning solution for predicting
heart disease using the UCI Heart Disease dataset.

Technology Stack
----------------
Python
Pandas
NumPy
Scikit-learn
MLflow
FastAPI
Pytest
Docker
Kubernetes
Prometheus
Grafana
GitHub Actions

Project Structure
-----------------
data/           Dataset files
notebooks/      EDA notebooks
src/            ML source code
models/         Trained model artifacts
api/            FastAPI application
tests/          Unit tests
deployment/     Kubernetes manifests
monitoring/     Monitoring configuration
screenshots/    Evidence screenshots
report/         Final report
